# brnf

**brnf** é um hub de dados para notas fiscais eletrônicas brasileiras. Ele ajuda a organizar dados de notas, validar CNPJs (inclusive no novo formato alfanumérico) e consultar seus registros.

- **Termos:** veja os [Termos de Uso](/termos)
- **Suporte:** [contato@alexandreb.dev](mailto:contato@alexandreb.dev)

O brnf é uma ferramenta de organização de dados. Ele não oferece consultoria tributária ou contábil, não emite notas fiscais e não faz envios a órgãos fiscais.
